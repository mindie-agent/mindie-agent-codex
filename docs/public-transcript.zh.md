# 公开对话采集与本地脱敏

<b>中文</b> | <a href="public-transcript.md">English</a> · <a href="README.md">返回文档索引</a>

当当前会话已通过 `/mindie-agent`（或 `$mindie-agent`，即 `entry_enabled = 1`）显式启用，且用户已为该会话所属的批准项目范围（`project_root`）开启社区贡献（`contribute`）时，`mindie-agent-codex` 会在 `Stop` 阶段从原生 Codex JSONL 会话记录中提取公开对话，在本地执行确定性脱敏并落盘为不可变 Markdown 分块，随后调用隔离小模型生成检索导航索引。未调用 `/mindie-agent` 的普通会话在 `Stop` 阶段会直接短路返回，不读取共享配置或会话记录。

---

## 1. 确定性的公开消息筛选

- **保留内容**：仅提取当前已激活 `/mindie-agent` 会话自激活边界（`max(created_at, activated_at)`）起的原生 `response_item` 记录中的用户输入、助手公开进展说明（Commentary）与最终回答。
- **剔除内容**：工具调用与返回载荷、隐藏推理过程（Reasoning）、系统与开发者提示词、注入的目录信息、重复包装层以及从父会话继承的 Fork 历史均被确定性剔除。附件占位符绝不会主动拉取外部文件或 URL。
- **完整性校验**：遇到缺失时间戳、记录损坏或范围不完整时直接报错，绝不静默跳过或推进采集游标。

---

## 2. Gitleaks `8.30.1` 与隐私规则本地脱敏

- **固定版本扫描器**：安装与更新时自动准备经哈希与许可证校验的 **Gitleaks `8.30.1`** 及确定性隐私规则。外部全局配置或正文中的 `gitleaks:allow` 注释均无法绕过扫描。
- **跨页流式扫描不缓存明文**：分页扫描仅跨页传递“未闭合多行私钥”的布尔状态，绝不在状态中缓存任何明文密钥。
- **一致性脱敏标记**：密钥凭证替换为标准脱敏占位符，敏感标识采用稳定 HMAC 替换（既隐藏真实值，又保持同一上下文内的引用一致性）。
- **原子事务落盘**：脱敏后的完整正文保存为不可变 Markdown 分块（单块上限 `16 KiB`），并与读取游标、清单绑定和索引任务在同一 SQLite 事务中原子提交。

---

## 3. 隔离的分块导航索引生成（`gpt-5.6-luna` / `low`）

- **仅生成导航元数据，绝不改写原文**：后台索引 Worker 使用固定策略（`gpt-5.6-luna`，`low` 推理强度，单次最多 8 个分块 / `64 KiB`）为新增分块生成标题、简短摘要与任务导航，**绝不替换或改写**脱敏后的 Markdown 原文。
- **纯净隔离运行环境**：若用户配置了自定义模型服务商，Worker 仅将该服务商的路由与认证字段投影到临时隔离目录中运行，不加载任何业务 Hook、Skill、MCP 服务或额外工具。
- **真实记账与禁止静默重试**：返回结果与实际 Token 用量在关闭子进程树前先行落盘保存。账本严格区分“已完成”、“失败”与“结果不确定”；失败或结果不确定的调用会阻止残缺包导出，且绝不自动发起重复的计费调用。
