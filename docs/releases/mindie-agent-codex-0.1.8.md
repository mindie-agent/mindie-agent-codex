# mindie-agent-codex 0.1.8

修复自动更新过程中对 Interrupt Hook MCP 服务名的硬编码校验。更新器现在按已验证发行包中的 Hook 和 MCP 清单核对原生宿主返回的处理器，仅继承此前已批准的 Hook，并保留用户禁用或撤销信任的选择。回归测试使用 Codex 0.164.0 实际返回的中断处理器数据。

保留 0.1.7 的发现边界：普通会话默认可发现 remote-dev、profiler、sim、coordinator 和本地 diagnostics 工具；knowledge 名称、描述与 schema 仅由显式启用后的私有 Skill 入口加载，npu-top 不注册为 Agent 工具。

已运行的 0.1.6 更新器仍包含旧校验逻辑，无法自行获得本补丁。若其已将 0.1.7 安装并准备完毕、但停在 Hook 信任迁移且尚未激活，需要用已验证的新版更新器恢复该次迁移，再检查最新版本；不得将失败记录改写为自动更新成功，也不得重放结果不明的外部写操作。

发布资产包含精确 Tag 源码的合同测试和公开消息解析微基准。它们不代表 NPU 性能或所有宿主的端到端验收。
