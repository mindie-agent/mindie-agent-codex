# MindIE Agent Codex v0.1.39 — Pre-`0.1.38` Live Session & Self-Upgrade Hardening

[中文](mindie-agent-codex-0.1.39.md)

- **In-flight `v0.1.34`–`v0.1.37` session compatibility after activation (Issues [`mindie-agent#381`](https://github.com/mindie-agent/mindie-agent/issues/381), [`mindie-agent#382`](https://github.com/mindie-agent/mindie-agent/issues/382))**: Adds thin `harness_update.py`, `runtime_call.py`, and `admission_ops.py` handoff shims so already-open `v0.1.34`–`v0.1.37` MCP servers and background `update_trigger._run` maintenance threads continue working cleanly without `FileNotFoundError` after `codex.json` switches to `0.1.39+`.

- **Automated `n-1 -> n` regression suite**: Adds `tests/test_legacy_self_upgrade.py` exercising `harness_update.py`, `runtime_call.py` (`catalog` + tool dispatch), `admission_ops.py`, POSIX symlink retention, and confirmed retirement semantics.
