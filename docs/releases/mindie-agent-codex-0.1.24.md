# mindie-agent-codex 0.1.24

[English](mindie-agent-codex-0.1.24.en.md)

发布已合入 #101 的激活子进程诊断改进，并锁定正式 diagnostics 0.5.9。故障记录保留真实异常类链、自有代码模块/函数/行号、栈指纹、类型化 errno 与失败子进程的包身份，避免父级包装异常覆盖原始证据。

先记录子进程原始故障，再复用 incident 引用；旧父版本仍可保留子进程事件。零退出码但未完成的激活也会留下诊断，结果仍是 incomplete，不改变原运行绑定或重试语义。现有上报授权、隐私投影、去重及 Hook 信任规则不变。

保留 0.1.23 的 Windows 原生目录深度打包修复、remote_probe 参数与解释器指引，继续使用已发布 remote-dev 0.11.7 和 coordinator 0.7.6。本次不修改 MCP 工具目录或权限。

本版本改善后续证据，不代表已经定位或修复 mindie-agent#324 的历史触发原因。发布、后台发现、候选安装、运行时激活和已加载宿主状态分别验证；现有宿主中的已加载脚本需自然重载。

正式工作流另行验证依赖 Release、精确 Tag 测试、benchmark、插件元数据和 SHA256SUMS。不声称原始用户故障复现或 NPU 验收。
