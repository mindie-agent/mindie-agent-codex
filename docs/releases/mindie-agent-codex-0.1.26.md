# mindie-agent-codex 0.1.26

[English](mindie-agent-codex-0.1.26.en.md)

本维护版修复版本发布、组件自动更新与原生插件激活之间的交付断点。默认仍追踪组件最新正式版本，并保留已安装版本和外部标准组件入口的版本下限。

- 本地运行时准备失败后，重新准备时读取当前绑定；已完成且明确未执行的 CAS 拒绝也可重新准备。尚未对账的外部安装与激活始终保留原始快照，不能盲目重放。
- 原生安装已确认完成、本地准备已结束时，即使较新原生版本清理了旧源码缓存，也会保留并退役旧记录，继续正常版本发现；本地准备失败不会因此变成永久 `unknown`。
- 发布前核对原生 MCP 入口的目标版本，阻止仅修改插件版本而遗漏生成入口的发布。当前原生入口与插件版本同步生成。
- 基线使用已正式发布的运行时组件；插件更新继续继承独立升级的组件和标准外部 sim/profiler 绑定，禁止降级。
- 本版将 sim/profiler 引导基线推进至 `0.9.10` / `0.5.11` 的精确源码提交，发布前必须通过这两个组件的正式资产与旧客户端校验。
- 发布从受保护主分支的统一工作流启动，完整草稿先通过旧更新器的真实整代升级和原生宿主验收，下载校验后才创建不可变 tag 并公开 Release；公开后再从旧安装验证正常更新源。
- 原生验收从正式 `0.1.23` 出发，覆盖组件独立升级、外部解释器绑定、Hook 显式禁用保留和新 MCP 进程工具发现。候选源与正式公开源的报告分别保留。

宿主兼容范围保留精确 `0.153.4` 或 `>=0.162.0-alpha.2 <=0.999.999`（含预发布）。区间内的新 patch、minor 和 alpha 版本无需逐个加入名单。实际测试、基准及升级结论以对应 CI 和随包验收报告为准，不将历史性能实验重标为本版本结果。
