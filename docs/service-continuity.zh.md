# 已安装服务身份与连续性

中文 | [English](service-continuity.md) · [返回文档索引](README.md)

本文说明 `mindie-agent-codex` 的锁定运行时布局、单一配置绑定与后台知识服务连续性契约。完整英文细则见 [`service-continuity.md`](service-continuity.md)。

## 1. 脱离易失缓存的锁定运行时

- 原生 Codex 负责插件分发与安装记录，`uv` 负责在宿主易失插件缓存之外（`PLUGIN_DATA/releases/0.0.1/`）构建非 editable 的锁定 Python 运行时。
- 用户适配器配置文件是唯一的安装绑定权威；已加载的稳定入口每次按完整绑定分派解释器与脚本，禁止混用不同版本的组件或原地覆盖已准备好的发行版字节。

## 2. 共享锁保护与空闲切换

- 在途业务调用持有共享操作锁；后台更新在锁外完成候选环境准备后，仅在确认旧服务空闲时获取排他锁退役旧服务并原子发布新绑定，无需用户手动重载会话。
