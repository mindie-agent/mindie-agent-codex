# Profiling limitations requiring evidence

- Kimi K3 historical captures include a 93-configured / 92-detected layer counterexample. Retain degraded or unknown status until the exact capture and config reconcile every complete step.
- Missing host events do not establish host blocking. Preserve null attribution and report trace coverage.
- A single rank cannot establish cross-rank synchronization or EP balance. GMM duration comparisons cover only the captured ranks and do not measure token counts directly.
- Ascend capture hardware provenance is required for peak-efficiency claims; the analysis computer is not hardware evidence.
- The current renderer is html_report_v2, with asset-pack and bounded single-file output. Skipped/error HTML is not a report.
